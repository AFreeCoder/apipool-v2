# 管理后台路由与钱包入口收敛开发报告

日期：2026-07-17

## 实际完成

- 删除网关运营页的路由、钱包页签，删除人工路由发布/退役 API 与服务。
- 新增目录驱动的路由快照生成器：从门户分组映射、模型基准价和分组比例推导上游路由与五维价格。
- 将 `model_route`、`model_price_version` 收敛为内部不可变运行快照，目录变化时自动滚动版本。
- 将 APIPool 调额改为本地钱包幂等调额；网关内部调额接口仅保留请求扣费冲正。
- 支付成功停止写模板 `credit` 和 New API 加额账本，只在订单事务内写本地钱包充值。
- 删除旧充值重试/对账 API 与远端充值执行器。
- 删除分组折扣的人工冒烟开关，目录可调用性与冒烟候选统一使用真实配置完整性条件。
- 用户详情、Dashboard、后台概览均改读本地钱包与请求账本。
- 更新当前产品、New API 边界、支付钱包和上线运行手册。

## 实现偏差与现场决策

- 原设想可以完全删除 `model_route` 和 `model_price_version`。实际结算、回填和审计需要锁定请求发生时的价格，因此保留两表，但禁止人工配置并改为自动快照。这不是第二套事实源。
- SQLite 并发测试发现每个请求都开启快照事务会与准入写入争锁。热路径改为先只读复用完全匹配的活动快照，仅目录变化时进入写事务。
- 旧 `smoke_tested` 数据库列没有随本次逻辑变更做破坏性表重建；应用层不再读取或写入该字段。
- 旧 `apipool_ledger_entry` 表和历史迁移保留用于既有数据审计，但当前支付、调额、后台概览和用户页面均不再写读它。
