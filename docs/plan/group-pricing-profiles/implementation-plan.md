# 分组定价档案实施计划

1. 新增定价档案、费率、listing 引用和不可变快照字段，生成 SQLite 迁移并加入一次性数据转换。
2. 实现分类约束、费率校验、SKU DSL 编译/执行和通用 `BigInt` 计费器。
3. 将发布就绪、快照、路由准入、响应结算和内部对账切换到新定价规格。
4. 将模型管理表单收敛为纯元数据，新增定价档案管理页，并让 listing 选择档案。
5. 将公开目录、初始化脚本和本地 smoke 切换到档案数据源。
6. 切断成本同步对售卖状态、发布快照和金额对账的写入或比较。
7. 更新并补充迁移、DSL、计费、发布、JSON/multipart 图片和端到端网关测试。
8. 运行类型检查、全量测试、lint、构建、Compose 校验和本地 smoke。
9. 使用内置浏览器完成官方分组与 Codex 特惠分组的真实 API UAT。
10. 冻结候选提交，复核远端基线、差异、备份与回滚点；推送 `main`，监控 CI/CD、
    生产备份、运行态、日志、资源和部署后 API UAT。
