## 四、证据与清理

每个失败项记录页面路径、用户可见现象、预期、实际结果和截图索引；真实调用另外记录脱敏请求关联标识及账本状态。不得写入或提交密码、API Key、New API token、完整用户身份、订单信息或原始敏感日志。

测试结束后停止门户服务，禁用合成用户的运行凭证，保留脱敏请求和账本证据；支付继续保持未测试状态。
