## 结论

本提交针对的四项修改均通过既定用户路径复测：

1. listing 折扣保存后，经站内客户端链接重新进入公开模型目录，价格立即更新，无需刷新页面或追加查询参数。
2. Checkout 关闭时，API Key 页面使用环境无关的余额说明，不再引导用户充值。
3. API Key 分组选择器完整显示“反代”和“官方”，用户界面不再出现 `Official`。
4. 余额页单独展示管理员余额调整，且不暴露内部原因或操作人标识。

另发现一个边界现象：浏览器“后退”会直接恢复先前公开目录的历史文档，仍可能显示保存前价格；随后通过“首页 → 模型与价格”的站内客户端导航会立即显示最新价格。该现象与本提交修复的应用路由缓存不同，已在 `issues.md` 单列跟踪。

Embedding 输出价设为 `0` 属后续配置复测，本提交未修改其计费逻辑，本轮不据此关闭 Embedding 遗留项。
