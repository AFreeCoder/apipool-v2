APIPool(下称"我们")尊重您的隐私。本隐私政策说明当您使用 APIPool 网站、控制台及 API 网关(统称"本服务")时,我们如何收集、使用、存储、保护和披露您的个人数据。本政策未定义的术语,含义以[用户协议](/terms-of-service)为准。

使用本服务即表示您同意我们按本隐私政策收集和使用您的个人数据。如果您不同意本政策的任何部分,请勿使用本服务。

## 1. 我们收集的数据

### 1.1 您主动提供的信息

- 账户信息:您的姓名、邮箱、密码(以哈希形式存储),以及您使用第三方登录(如 Google、GitHub)时由登录提供方提供的标识。
- 通信记录:您与我们的往来记录,包括支持邮件。

### 1.2 支付信息

付款由第三方支付处理机构处理,目前为 [Stripe](https://stripe.com) 和 [Creem](https://www.creem.io)。您的卡号等敏感支付信息由这些机构收集和处理,我们不收集。我们保留订单号、金额、币种、支付状态和时间等交易记录,用于计费与对账。

### 1.3 自动收集的信息

当您使用本服务时,我们会自动收集技术信息,如 IP 地址、浏览器类型与版本、操作系统、时区、访问页面,以及用于安全、支持和事故复盘的服务端请求日志(请求标识、错误码和审计事件)。

### 1.4 API 用量数据

为运营网关并对您的用量计费,我们记录:

- API Key 元数据:脱敏展示、Key 状态、创建时间和内部绑定标识。Key 明文仅在创建时展示一次,之后不再展示。
- 用量与账单数据:额度余额、请求数、Token 总量、所用模型、时间戳、状态码、最近用量日志,以及额度账本记录(包括调整、操作者、原因和回滚状态)。

### 1.5 API 输入与输出

您通过 API 提交的内容(下称"输入")会被传输给相应的上游 AI 模型提供方以生成响应(下称"输出")。我们不会使用您的输入或输出训练 AI 模型。我们仅保留计费、滥用防范和支持所需的运营日志。上游提供方按其自身隐私政策处理您的内容,例如:

- OpenAI:https://openai.com/policies/privacy-policy
- Anthropic:https://www.anthropic.com/legal/privacy
- Google:https://policies.google.com/privacy

## 2. Cookie 与分析

我们使用严格必要的 Cookie 维持您的登录状态并保护会话安全。这类 Cookie 是本服务正常运行所必需的,无法禁用。

我们还可能使用分析服务(如 Google Analytics 或类似工具)了解访问者如何使用网站,以改进本服务。分析数据以汇总形式收集,不用于定向广告。您可以通过浏览器设置拒绝或删除 Cookie;禁用 Cookie 可能导致本服务部分功能无法正常使用。

## 3. 数据用途

我们将您的个人数据用于:

- 提供本服务,包括身份认证、API Key 管理、请求转发、余额与用量展示;
- 处理付款并维护准确的账单记录;
- 发送服务通知,如邮箱验证、账户与账单通知、政策变更通知;
- 回应您的咨询和支持请求;
- 监测、防范和调查欺诈、滥用、安全事件及违反用户协议的行为;
- 遵守适用法律法规;
- 分析汇总用量以运营和改进本服务。

我们不出售您的个人数据。

## 4. 数据共享

我们仅在以下情形共享个人数据:

- 服务提供商:与协助我们运营本服务的供应商共享,如云托管、支付处理(Stripe、Creem)、邮件发送和分析服务商。其只能为代表我们执行任务而访问个人数据,并有义务予以保护。
- 上游 AI 模型提供方:为生成响应所必需,您的 API 输入会被传输给相应的模型提供方。
- 法律要求:法律、法规、司法程序或政府要求需要披露时,或我们善意认为披露是执行条款、保护本服务安全、保护 APIPool、用户或公众的权利、财产或安全所合理必需时。
- 企业交易:发生合并、收购、重组或资产出售时,我们会要求承继方继续遵守本隐私政策。
- 经您同意:在取得您同意的情况下用于已向您披露的其他目的。

## 5. 您的权利与选择

根据您的居住地及适用法律(包括 GDPR 和美国部分州的隐私法),您可能享有以下权利:

- 知情权:了解我们处理您哪些个人数据,并请求访问及获取可携带副本;
- 更正权:请求更正不准确的个人数据;
- 删除权:请求删除您的个人数据和账户;
- 反对权与限制处理权:就特定处理提出反对或请求限制;
- 撤回同意权:在处理基于同意时撤回同意,撤回不影响撤回前处理的合法性。

如需行使上述权利,请联系 [support@apipool.dev](mailto:support@apipool.dev)。处理请求前,我们可能需要先验证您的身份;在法律允许的情况下,我们可能拒绝部分请求。

## 6. 数据安全

我们采取技术和管理措施保护您的数据,包括加密传输(HTTPS)、密码哈希存储、API Key 脱敏展示、敏感凭据加密存储,以及对状态变更操作记录审计日志。

任何传输或存储方式都无法做到绝对安全。您有责任妥善保管密码和 API Key。如您认为账户已被入侵,请立即联系我们。

## 7. 数据保留

在您的账户处于活跃状态期间,或在提供本服务、履行法律和会计义务(如交易记录)、解决争议和执行协议所需的期限内,我们会保留您的个人数据。数据不再需要时,我们会将其删除或转换为匿名形式。

## 8. 用户资格与儿童隐私

本服务仅面向年满 18 周岁、位于中国大陆以外地区的用户。我们不会有意收集 18 周岁以下人士的个人数据。如您认为有未成年人向我们提供了个人数据,请联系我们,我们会予以删除。

## 9. 跨境数据传输

您的个人数据可能存储和处理于您所在国家或地区以外的服务器上。在适用法律有要求时(如 GDPR 对欧洲经济区或英国以外传输的要求),我们会采取适当保障措施,如充分性认定或标准合同条款。

## 10. 政策变更

我们可能不时更新本隐私政策。修订后的政策会发布在本页面,并更新"最后更新日期"。对于重大变更,我们会提前通过邮件或网站公告通知注册用户。变更生效后您继续使用本服务,即视为接受修订后的政策。

## 11. 适用法律

因本隐私政策引起或与之相关的任何争议,受香港法律管辖,不适用其法律冲突规则。

## 12. 联系我们

如有隐私相关问题或需行使您的权利,请联系 [support@apipool.dev](mailto:support@apipool.dev)。
