## 概述

APIPool 是用于发放 API Key、展示用量并通过 APIPool API 网关转发请求的 API 门户。MVP 阶段只保存运营服务所需的账户信息、Key 元数据、用量快照、最近日志快照和人工调额账本记录。

## 我们收集的数据

- 账户信息：姓名、邮箱、登录提供方标识和会话元数据。
- API Key 元数据：脱敏展示、Key 状态、创建时间、禁用/删除状态，以及关联的 APIPool 内部绑定标识。
- 用量和账单数据：额度余额、请求数、Token 总量、最近用量日志、人工调额记录、操作者、原因和回滚状态。
- 运营日志：服务端请求标识、错误码和用于支持及事故复盘的审计事件。

## 数据用途

我们使用这些数据完成用户认证、创建和管理 API Key、展示余额和用量、执行人工调额、排查服务端操作失败，以及保护服务免受滥用。

## 数据共享

APIPool 不出售用户数据。MVP 阶段，真实额度执行和用量扣费由 APIPool 的服务端系统完成。相关调用仅在服务端执行，浏览器不会获得内部用户标识。

## 安全

API Key 明文只在创建后展示一次。已保存的 Key 仅以脱敏形式展示。所有管理凭据必须保存在服务端环境变量中。所有远端状态变更操作都会写入审计日志。
