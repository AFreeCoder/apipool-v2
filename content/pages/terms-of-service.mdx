## Terms

By using APIPool, you agree to use the portal and API gateway only for lawful API workloads and in accordance with the limits assigned to your account.

## MVP Service Scope

The MVP provides account login, API key creation, manual quota adjustment, balance and usage views, recent logs, and one verified launch model through `https://api.apipool.dev/v1`. Payments, refunds, automatic top-ups, migrations, playgrounds, exports, and organization budgets are not part of the MVP.

## API Keys

You are responsible for keeping API keys secret. Key plaintext is shown once after creation. APIPool may disable keys for abuse, suspected compromise, operational risk, or breach of these terms.

## Quota And Billing Records

New users start with zero quota. Quota adjustments are performed manually by operators and recorded in the APIPool ledger with operator, reason, internal change identifier, status, and rollback state.

## Availability

The service is provided on an as-is basis during MVP. We may change available models, pricing display, or access rules while keeping actual APIPool API usage as the source of truth for deduction.
