APIPool（「我們」）尊重您的隱私。本隱私政策說明，當您使用 APIPool 網站、控制台和 API 閘道（統稱「本服務」）時，我們如何收集、使用、儲存、保護和揭露您的個人資料。本政策未定義的術語，含義以[服務條款](/terms-of-service)為準。

使用本服務即表示您同意我們按照本隱私政策收集和使用您的個人資料。如果您不同意本政策的任何部分，請勿使用本服務。

## 1. 我們收集的資料

### 1.1 您主動提供的資訊

- 帳戶資訊：您的姓名、電子郵件地址、密碼（以雜湊形式儲存），以及您使用第三方登入（例如 Google 或 GitHub）時由登入提供方提供的識別碼。
- 通訊紀錄：您與我們的往來紀錄，包括支援郵件。

### 1.2 付款資訊

付款由第三方支付處理機構處理，目前包括 [Stripe](https://stripe.com) 和 [Creem](https://www.creem.io)。您的信用卡號和其他敏感付款資訊由這些處理機構收集和處理，而不是由我們收集和處理。我們會保留訂單號、金額、幣別、付款狀態和時間戳記等交易紀錄，用於計費和對帳。

### 1.3 自動收集的資訊

當您使用本服務時，我們會自動收集技術資訊，例如 IP 位址、瀏覽器類型和版本、作業系統、時區、造訪頁面，以及用於安全、支援和事故複盤的伺服器端請求日誌（請求識別碼、錯誤碼和稽核事件）。

### 1.4 API 用量資料

為營運閘道並對您的用量計費，我們會記錄：

- API Key 中繼資料：脫敏後的 Key 顯示值、Key 狀態、建立時間和內部綁定識別碼。Key 明文只在建立時顯示一次，之後不再顯示。
- 用量與計費資料：餘額、請求數、Token 總量、使用模型、時間戳記、狀態碼、近期用量日誌，以及額度帳本紀錄（包括調整、操作者、原因和回滾狀態）。

### 1.5 API 輸入與輸出

您透過 API 提交的內容（「輸入」）會被傳輸給相應的上游 AI 模型供應商，以產生回應（「輸出」）。我們不會使用您的輸入或輸出訓練 AI 模型。我們僅保留計費、防止濫用和支援所需的營運日誌。上游供應商會按照其自身隱私政策處理您的內容，例如：

- OpenAI: https://openai.com/policies/privacy-policy
- Anthropic: https://www.anthropic.com/legal/privacy
- Google: https://policies.google.com/privacy

## 2. Cookie 與分析

我們使用嚴格必要的 Cookie 來保持您的登入狀態並保護工作階段安全。這些 Cookie 是本服務運作所必需的，無法停用。

我們還可能使用分析服務（例如 Google Analytics 或類似工具）了解訪客如何使用網站，以改進本服務。分析資料以彙總形式收集，不用於定向廣告。您可以透過瀏覽器設定拒絕或刪除 Cookie；停用 Cookie 可能導致本服務的部分功能無法正常使用。

## 3. 我們如何使用您的資料

我們將您的個人資料用於：

- 提供本服務，包括身分驗證、API Key 管理、請求路由，以及餘額和用量顯示；
- 處理付款並維護準確的帳單紀錄；
- 傳送服務通知，例如電子郵件驗證、帳戶和帳單通知，以及政策變更通知；
- 回應您的問題和支援請求；
- 監測、防範和調查詐欺、濫用、安全事件以及違反服務條款的行為；
- 遵守適用法律法規；以及
- 分析彙總用量，以營運和改進本服務。

我們不出售您的個人資料。

## 4. 我們如何共享您的資料

我們僅在以下情形共享個人資料：

- 服務供應商：與協助我們營運本服務的供應商共享，例如雲端託管、付款處理（Stripe、Creem）、電子郵件寄送和分析服務供應商。它們只能為代表我們執行任務而存取個人資料，並有義務保護這些資料。
- 上游 AI 模型供應商：為產生回應所必需，您的 API 輸入會被傳輸給相應的模型供應商。
- 法律要求：在法律、法規、法律程序或政府要求需要揭露時，或我們善意認為揭露是執行條款、保護本服務安全，或保護 APIPool、使用者或公眾的權利、財產或安全所合理必需時。
- 公司交易：在合併、收購、重組或資產出售相關情形中共享；在這種情況下，我們會要求承繼方繼續遵守本隱私政策。
- 經您同意：用於已向您揭露並取得您同意的其他目的。

## 5. 您的權利與選擇

根據您的居住地和適用法律（包括 GDPR 以及美國部分州隱私法），您可能享有以下權利：

- 了解我們處理了您的哪些個人資料，並請求存取和取得可攜式副本；
- 請求更正不準確的個人資料；
- 請求刪除您的個人資料和帳戶；
- 反對或請求限制某些處理；以及
- 在處理基於同意時撤回同意，且不影響撤回前處理的合法性。

如需行使上述權利，請聯絡 [support@apipool.dev](mailto:support@apipool.dev)。我們可能會在處理請求前要求您驗證身分，並可能在法律允許的情況下拒絕部分請求。

## 6. 資料安全

我們採取技術和管理措施保護您的資料，包括加密傳輸（HTTPS）、雜湊密碼儲存、API Key 脫敏顯示、敏感憑證加密儲存，以及對狀態變更操作記錄稽核日誌。

任何傳輸或儲存方式都無法做到絕對安全。您有責任妥善保管密碼和 API Key。如果您認為帳戶已遭入侵，請立即聯絡我們。

## 7. 資料保留

只要您的帳戶處於活動狀態，或為提供本服務、遵守法律和會計義務（例如交易紀錄）、解決爭議和執行協議所必需，我們會保留您的個人資料。當資料不再需要時，我們會將其刪除或匿名化。

## 8. 使用資格與兒童隱私

本服務僅面向年滿 18 歲、位於中國大陸以外地區的使用者。我們不會有意收集 18 歲以下人員的個人資料。如果您認為未成年人向我們提供了個人資料，請聯絡我們，我們會將其刪除。

## 9. 跨境資料傳輸

您的個人資料可能儲存和處理在您所在國家或地區以外的伺服器上。在適用法律有要求時（例如 GDPR 對歐洲經濟區或英國以外傳輸的要求），我們會依賴適當保障措施，例如充分性認定或標準合約條款。

## 10. 政策變更

我們可能不時更新本隱私政策。修訂後的政策會發布在本頁面，並更新「最後更新日期」。對於重大變更，我們會提前透過電子郵件或網站通知註冊使用者。變更生效後您繼續使用本服務，即表示接受修訂後的政策。

## 11. 準據法

因本隱私政策引起或與之相關的任何爭議，均受香港法律管轄，且不適用其法律衝突原則。

如有隱私相關問題或需要行使您的權利，請聯絡 [support@apipool.dev](mailto:support@apipool.dev)。
