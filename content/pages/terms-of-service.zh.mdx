本用户协议(下称"本协议")是您与 APIPool(下称"APIPool""我们")之间,就您访问和使用 APIPool 网站、控制台及 API 网关(统称"本服务")达成的法律协议。

访问或使用本服务,或点击接受本协议,即表示您已阅读、理解并同意受本协议及我们的[隐私政策](/privacy-policy)约束。如果您不同意本协议,或不属于第 2 条所述的适格用户,请勿访问或使用本服务。

## 1. 服务概述

APIPool 运营一个大语言模型(LLM)API 网关,用户可通过统一的、兼容 OpenAI 格式的 API 访问第三方生成式 AI 模型(下称"AI 模型")。我们可能随时增加、移除或替换本服务提供的 AI 模型,恕不另行通知。

## 2. 用户资格与服务地区

### 2.1 年龄要求

您必须年满 18 周岁方可使用本服务。

### 2.2 服务地区

本服务仅面向中国大陆以外地区的用户提供。APIPool 不向中国大陆地区用户提供服务。我们提供中文支持是为了服务全球华语用户,这不改变本服务的地区范围。

如果您所在地区的法律法规禁止或限制使用本服务,您应遵守当地法律,不得使用本服务。您同意不采取任何技术手段规避地区限制。

### 2.3 陈述与保证

使用本服务即表示您陈述并保证:

- 您已年满 18 周岁,且具有订立本协议的完全民事行为能力;
- 如您代表公司或其他组织使用本服务,您已获得使该组织受本协议约束的有效授权;
- 您注册和使用本服务符合适用于您的所有法律法规;
- 您不位于中国大陆或其他禁止、限制使用本服务的司法辖区,也不会从上述地区访问本服务。

## 3. 账户与注册

使用本服务的多数功能需要注册账户,您可以使用邮箱或受支持的第三方登录方式(如 Google、GitHub)注册。您同意提供准确的信息并保持其有效。使用本服务前,您可能需要先完成邮箱验证。

您应自行负责妥善保管账户凭据,并对账户项下发生的全部活动负责。如您认为账户安全受到威胁,请立即联系 [support@apipool.dev](mailto:support@apipool.dev)。

## 4. API Key

您有义务保管好您的 API Key。Key 明文仅在创建时展示一次。使用您 API Key 发起的全部请求均计入您的账户,您应对由此产生的用量和费用负责。

如出现滥用、疑似泄露、运营风险或违反本协议的情况,APIPool 可随时禁用或吊销相关 API Key。

## 5. 付费与额度

### 5.1 预付额度

使用本服务需要为账户购买预付额度(下称"额度")。额度按您对 AI 模型的实际用量扣减,不是按月订阅。每次购买前,我们会展示费用明细,包括购买币种,并经您确认。

额度不是现金、第三方发行的储值、礼品卡、存款账户或支付工具。额度仅可用于您使用 APIPool 自营服务。额度不具有现金价值,不产生利息,不得转让、转售、提现、兑换现金,也不得用于购买 APIPool 以外任何主体提供的商品或服务。

APIPool 仅提供数字 API 访问服务,不涉及实体商品配送。支付成功后,购买的额度通常会自动加入您的 APIPool 账户,并可通过控制台和 API Key 使用。

受支付审核、网络故障、网关延迟或对账检查影响,额度到账可能出现延迟。如果您的付款已成功但账户未显示相应额度,或额度状态显示为处理中或失败,请通过 [support@apipool.dev](mailto:support@apipool.dev) 联系我们,并提供账户邮箱和订单信息。我们会进行核查,并在适当情况下人工补发额度或按下方退款政策处理退款。

### 5.3 退款政策

除适用法律另有强制规定外,已购额度一经交付并可使用后不予退款。已消耗额度以及免费、促销或人工赠送额度不予退款。

### 7.1 输入与输出

您可以向本服务提交文本、数据或其他内容(下称"输入"),并获得 AI 模型生成的内容(下称"输出",与输入合称"用户内容")。在您与 APIPool 之间,您保留对输入所享有的全部权利;您对输出的权利受相应 AI 模型提供方条款的约束。
