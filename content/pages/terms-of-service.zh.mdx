## 条款

使用 APIPool 即表示您同意仅将门户和 API 网关用于合法 API 工作负载，并遵守账户分配的额度限制。

## MVP 服务范围

MVP 提供账户登录、API Key 创建、人工调额、余额与用量视图、最近日志，以及通过 `https://api.apipool.dev/v1` 调用的一个已验证首发模型。支付、退款、自动充值、迁移、Playground、导出和组织预算不在 MVP 范围内。

## API Key

您需要自行保管 API Key。Key 明文只会在创建后展示一次。若出现滥用、疑似泄露、运营风险或违反本条款的情况，APIPool 可以禁用相关 Key。

## 额度与账单记录

新用户默认 0 额度。额度调整由运营人工执行，并记录在 APIPool 账本中，包含操作者、原因、内部变更标识、状态和回滚状态。

## 可用性

MVP 阶段服务按现状提供。我们可能调整可用模型、价格展示或访问规则；实际扣费以 APIPool API 用量为准。
