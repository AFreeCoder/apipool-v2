## Base URL

```text
https://api2.apipool.dev
```

One provider-neutral endpoint and one key for every model. Add the protocol path
that matches your SDK or provider-compatible format:

- **OpenAI-compatible protocol (default)** — every model, regardless of vendor,
  can be called through `/v1/chat/completions`. Most SDKs and tools work by
  appending the OpenAI-compatible `/v1` prefix to the APIPool endpoint.
- **Vendor-native protocols** — the same endpoint and key also serve native
  formats, such as Anthropic's Messages API at `/v1/messages`. Use these when
  your tooling expects a vendor's own protocol.

## Authentication

Send your key in the `Authorization` header:

```text
Authorization: Bearer $APIPOOL_API_KEY
```

Create keys in the [console](/dashboard/api-keys). The full key is shown only
once after creation — the list shows a masked value afterward.

## Get started

1. [Sign up](/sign-up) and open the console.
2. Add credit on the [balance page](/dashboard/billing). Usage is billed per
   token; your balance never expires.
3. [Create an API key](/dashboard/api-keys) and copy it once.
4. Call any model from the [model list](/models) using the examples below.

## curl

```bash
APIPOOL_ENDPOINT="https://api2.apipool.dev"

curl "$APIPOOL_ENDPOINT/v1/chat/completions" \
  -H "Authorization: Bearer $APIPOOL_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"gpt-4o-mini","messages":[{"role":"user","content":"Hello from APIPool"}]}'
```

## OpenAI SDK (JavaScript)

```ts
import OpenAI from 'openai';

const APIPOOL_ENDPOINT = 'https://api2.apipool.dev';

const client = new OpenAI({
  baseURL: `${APIPOOL_ENDPOINT}/v1`,
  apiKey: process.env.APIPOOL_API_KEY,
});

const completion = await client.chat.completions.create({
  model: 'gpt-4o-mini',
  messages: [{ role: 'user', content: 'Hello from APIPool' }],
});

console.log(completion.choices[0].message.content);
```

## OpenAI SDK (Python)

```python
import os
from openai import OpenAI

APIPOOL_ENDPOINT = "https://api2.apipool.dev"

client = OpenAI(
    base_url=f"{APIPOOL_ENDPOINT}/v1",
    api_key=os.environ["APIPOOL_API_KEY"],
)

completion = client.chat.completions.create(
    model="gpt-4o-mini",
    messages=[{"role": "user", "content": "Hello from APIPool"}],
)

print(completion.choices[0].message.content)
```

## Plain HTTP (fetch)

```ts
const APIPOOL_ENDPOINT = 'https://api2.apipool.dev';

const response = await fetch(`${APIPOOL_ENDPOINT}/v1/chat/completions`, {
  method: 'POST',
  headers: {
    Authorization: `Bearer ${process.env.APIPOOL_API_KEY}`,
    'Content-Type': 'application/json',
  },
  body: JSON.stringify({
    model: 'gpt-4o-mini',
    messages: [{ role: 'user', content: 'Hello from APIPool' }],
  }),
});

console.log(await response.json());
```

## Native protocols (Anthropic Messages)

Claude models can also be called with Anthropic's native Messages API — same
base URL, same key:

```bash
APIPOOL_ENDPOINT="https://api2.apipool.dev"

curl "$APIPOOL_ENDPOINT/v1/messages" \
  -H "x-api-key: $APIPOOL_API_KEY" \
  -H "anthropic-version: 2023-06-01" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "claude-sonnet-4",
    "max_tokens": 1024,
    "messages": [{ "role": "user", "content": "Hello!" }]
  }'
```

The official Anthropic SDKs work by setting `baseURL` to
`https://api2.apipool.dev` and `apiKey` to your APIPool key.

## Streaming

Set `"stream": true` in the request body to receive server-sent events, exactly
like the OpenAI API. The official SDKs handle this with their built-in
streaming helpers.

## Error reference

| Status                | Meaning                                    | What to do                                     |
| --------------------- | ------------------------------------------ | ---------------------------------------------- |
| `401`                 | Key missing, invalid, disabled, or deleted | Check the header and key status in the console |
| `403`                 | Key has no access to the requested model   | Review the key's model restrictions            |
| `429`                 | Rate limited                               | Retry with backoff                             |
| `402` / quota error   | Balance is exhausted                       | Add credit in the console                      |
| `404` model_not_found | Model ID not available                     | Pick a model from the [model list](/models)    |

## Billing

Top up in dollars on the [balance page](/dashboard/billing); usage is deducted
per token at the prices listed on the [models page](/models). Requests, tokens,
and per-model spend appear on the [usage page](/dashboard/usage).
