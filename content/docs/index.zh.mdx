## Base URL

```text
https://app.apipool.dev
```

一个协议中立的 endpoint、一个 Key 调用所有模型。具体请求路径由你选择的 SDK 或
provider-compatible 协议决定：

- **OpenAI 兼容协议（默认）**——所有模型（无论厂商）都可以通过
  `/v1/chat/completions` 调用；OpenAI SDK 这类工具需要把 OpenAI-compatible
  `/v1` 前缀追加到 APIPool endpoint 后。
- **各家原生协议**——同一入口与 Key 也直接支持厂商原生格式，例如 Anthropic 的
  Messages API（`/v1/messages`）。当你的工具链依赖厂商原生协议时使用。

## 鉴权

在 `Authorization` header 中携带你的 Key：

```text
Authorization: Bearer $APIPOOL_API_KEY
```

在[控制台](/dashboard/api-keys)创建 Key。完整 Key 只在创建后展示一次，列表中
此后只显示掩码。

## 开始使用

1. [注册](/sign-up)并进入控制台。
2. 在[余额页](/dashboard/billing)充值。按 token 用量计费，余额永不过期。
3. [创建 API Key](/dashboard/api-keys) 并立即保存。
4. 从[模型列表](/models)选择模型，参考下方示例调用。

## curl

```bash
APIPOOL_ENDPOINT="https://app.apipool.dev"

curl "$APIPOOL_ENDPOINT/v1/chat/completions" \
  -H "Authorization: Bearer $APIPOOL_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"gpt-5.6-luna","messages":[{"role":"user","content":"Hello from APIPool"}]}'
```

## OpenAI SDK（JavaScript）

```ts
import OpenAI from 'openai';

const APIPOOL_ENDPOINT = 'https://app.apipool.dev';

const client = new OpenAI({
  baseURL: `${APIPOOL_ENDPOINT}/v1`,
  apiKey: process.env.APIPOOL_API_KEY,
});

const completion = await client.chat.completions.create({
  model: 'gpt-5.6-luna',
  messages: [{ role: 'user', content: 'Hello from APIPool' }],
});

console.log(completion.choices[0].message.content);
```

## OpenAI SDK（Python）

```python
import os
from openai import OpenAI

APIPOOL_ENDPOINT = "https://app.apipool.dev"

client = OpenAI(
    base_url=f"{APIPOOL_ENDPOINT}/v1",
    api_key=os.environ["APIPOOL_API_KEY"],
)

completion = client.chat.completions.create(
    model="gpt-5.6-luna",
    messages=[{"role": "user", "content": "Hello from APIPool"}],
)

print(completion.choices[0].message.content)
```

## 原生 HTTP（fetch）

```ts
const APIPOOL_ENDPOINT = 'https://app.apipool.dev';

const response = await fetch(`${APIPOOL_ENDPOINT}/v1/chat/completions`, {
  method: 'POST',
  headers: {
    Authorization: `Bearer ${process.env.APIPOOL_API_KEY}`,
    'Content-Type': 'application/json',
  },
  body: JSON.stringify({
    model: 'gpt-5.6-luna',
    messages: [{ role: 'user', content: 'Hello from APIPool' }],
  }),
});

console.log(await response.json());
```

## 原生协议（Anthropic Messages）

Claude 系列模型也可以用 Anthropic 原生 Messages API 调用——同一 Base URL、同一 Key：

```bash
APIPOOL_ENDPOINT="https://app.apipool.dev"

curl "$APIPOOL_ENDPOINT/v1/messages" \
  -H "x-api-key: $APIPOOL_API_KEY" \
  -H "anthropic-version: 2023-06-01" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "claude-sonnet-4",
    "max_tokens": 1024,
    "messages": [{ "role": "user", "content": "Hello!" }]
  }'
```

Anthropic 官方 SDK 将 `baseURL` 设为 `https://app.apipool.dev`、`apiKey` 设为你的
APIPool Key 即可使用。

## Embeddings 与 Images

Embedding 使用 `/v1/embeddings`，只按输入 token 计费；将模型替换为
[模型列表](/models)中支持 Embedding 的可用模型：

```bash
curl "$APIPOOL_ENDPOINT/v1/embeddings" \
  -H "Authorization: Bearer $APIPOOL_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"YOUR_EMBEDDING_MODEL","input":"Hello from APIPool"}'
```

图片生成使用 `/v1/images/generations`，图片编辑使用 multipart 的
`/v1/images/edits`。图片模型按公开模型页列出的 quality/size SKU **按实际返回张数、按次计费**；Images 不支持 `stream:true`。

```bash
curl "$APIPOOL_ENDPOINT/v1/images/generations" \
  -H "Authorization: Bearer $APIPOOL_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"gpt-image-2","prompt":"A product photo on a white background","quality":"low","size":"1024x1024"}'
```

## 流式输出

Chat Completions、Responses 与 Messages 请求可设置 `"stream": true`，获得 SSE
流式响应；Images 端点不支持流式响应。

## 错误码参考

| 状态码                           | 含义                           | 处理方式                          |
| -------------------------------- | ------------------------------ | --------------------------------- |
| `401`                            | Key 缺失、无效、被禁用或已删除 | 检查 header 与控制台中的 Key 状态 |
| `403`                            | Key 无权访问所请求的模型       | 检查 Key 的模型限制设置           |
| `429` insufficient_quota         | 门户余额耗尽                   | 在控制台充值                      |
| `429` concurrency_limit_exceeded | 触发并发风险限制               | 按 `Retry-After` 退避后重试       |
| `404` model_not_found            | 模型 ID 不可用                 | 从[模型列表](/models)选择可用模型 |

## 计费说明

在[余额页](/dashboard/billing)以美元充值。文本与 Embedding 按[模型页](/models)
所列 meter/token 单价扣减，图片等按次模型按 SKU 单价与实际返回数量扣减。请求数、
token 数、分模型消费和逐请求扣费在[用量页](/dashboard/usage)与账单页可见。
