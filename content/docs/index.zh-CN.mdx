## Base URL

```text
https://api.apipool.dev/v1
```

一个 Base URL、一把 API Key，就能调用所有模型。APIPool 支持两种调用方式：

- **OpenAI 兼容协议（默认）**——无论模型来自哪家供应商，都可以通过
  `/v1/chat/completions` 调用。多数 SDK 和工具只需把 `baseURL` 指向 APIPool。
- **供应商原生协议**——同一个入口、同一把 API Key 也支持供应商原生格式，例如
  Anthropic Messages API 的 `/v1/messages`。当你的工具链要求供应商原生协议时使用。

## 鉴权

在 `Authorization` 请求头中携带 API Key：

```text
Authorization: Bearer $APIPOOL_API_KEY
```

在[控制台](/dashboard/api-keys)创建 API Key。完整 Key 只在创建后展示一次，之后列表仅展示掩码。

## 开始使用

1. [注册](/sign-up)并进入控制台。
2. 在[余额页](/dashboard/billing)充值。用量按 token 计费，余额永不过期。
3. [创建 API Key](/dashboard/api-keys)，并立即复制保存。
4. 从[模型列表](/models)选择模型，参考下方示例发起调用。

## curl

```bash
curl https://api.apipool.dev/v1/chat/completions \
  -H "Authorization: Bearer $APIPOOL_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"gpt-4o-mini","messages":[{"role":"user","content":"Hello from APIPool"}]}'
```

## OpenAI SDK（JavaScript）

```ts
import OpenAI from 'openai';

const client = new OpenAI({
  baseURL: 'https://api.apipool.dev/v1',
  apiKey: process.env.APIPOOL_API_KEY,
});

const completion = await client.chat.completions.create({
  model: 'gpt-4o-mini',
  messages: [{ role: 'user', content: 'Hello from APIPool' }],
});

console.log(completion.choices[0].message.content);
```

## OpenAI SDK（Python）

```python
import os
from openai import OpenAI

client = OpenAI(
    base_url="https://api.apipool.dev/v1",
    api_key=os.environ["APIPOOL_API_KEY"],
)

completion = client.chat.completions.create(
    model="gpt-4o-mini",
    messages=[{"role": "user", "content": "Hello from APIPool"}],
)

print(completion.choices[0].message.content)
```

## 直接 HTTP（fetch）

```ts
const response = await fetch("https://api.apipool.dev/v1/chat/completions", {
  method: "POST",
  headers: {
    Authorization: `Bearer ${process.env.APIPOOL_API_KEY}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    model: "gpt-4o-mini",
    messages: [{ role: "user", content: "Hello from APIPool" }],
  }),
});

console.log(await response.json());
```

## 原生协议（Anthropic Messages）

Claude 系列模型也可以通过 Anthropic 原生 Messages API 调用——Base URL 相同，API Key 也相同：

```bash
curl https://api.apipool.dev/v1/messages \
  -H "x-api-key: $APIPOOL_API_KEY" \
  -H "anthropic-version: 2023-06-01" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "claude-sonnet-4",
    "max_tokens": 1024,
    "messages": [{ "role": "user", "content": "Hello!" }]
  }'
```

Anthropic 官方 SDK 只需将 `baseURL` 设置为 `https://api.apipool.dev`，并将 `apiKey`
设置为你的 APIPool API Key。

## 流式输出

在请求体中设置 `"stream": true` 即可接收服务器发送事件（SSE），行为与 OpenAI API
一致。官方 SDK 内置的流式辅助方法可以直接使用。

## 错误码参考

| 状态码 | 含义 | 处理方式 |
| ------ | ---- | -------- |
| `401`  | Key 缺失、无效、被禁用或已删除 | 检查请求头和控制台中的 Key 状态 |
| `403`  | Key 无权访问请求的模型 | 检查 Key 的模型限制 |
| `429`  | 触发限流 | 退避后重试 |
| `402` / quota error | 余额已用完 | 在控制台充值 |
| `404` model_not_found | 模型 ID 不可用 | 从[模型列表](/models)选择可用模型 |
